#### 🚀 Featured Project: AtmoPulse (Beta Launch: Autumn 2026)
I am currently engineering **AtmoPulse**, an interactive web-based analytical tool designed to dynamically track and contextualize pan-European synoptic extremes.
* **The Innovation:** It operationalizes anomaly tracking and predictive persistence by fusing live atmospheric forecasting (IFS/AIFS) with shifting historical climate baselines (ERA5).
* **Scientific Rigor:** To ensure physical consistency, IFS surface temperature parameters are calibrated via Quantile Delta Mapping (QDM) to neutralize model biases and orographic resolution artifacts, while mid-tropospheric circulation fields retain their physical integrity
* **The Architecture:** Designed with a Dual-Mode interface (Standard vs. Expert) to serve both media/educators/public and meteorologists/climatologists, AtmoPulse solves traditional latency bottlenecks. It pre-calculates complex spatial matrices via Python background tasks (xarray, numpy) and stores them as ultra-lightweight binaries, allowing milliseconds-rendering of 0.25° grid data
